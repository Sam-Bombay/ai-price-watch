AI Price Watch JSON

The same daily price pull that feeds the site, as stable JSON. Built for agents and cost tools that need today's numbers without a browser.

EndpointReturns
/api/prices.jsoncurrent price per model, USD per 1M tokens, plus context window
/api/changes.jsonevery logged price change, oldest first
/api/index.jsonmachine-readable index of the two above

Shape

{
  "schema": "ai-price-watch/prices",
  "version": "1",
  "updated": "2026-11-19",
  "count": 479,
  "units": {"in":"USD per 1M input tokens","out":"USD per 1M output tokens","ctx":"tokens"},
  "models": [{"id":"mistralai/mistral-nemo","name":"Mistral: Mistral Nemo","in":0.029,"out":0.03,"ctx":131072}]
}

Use it

curl -s https://sam-bombay.github.io/ai-price-watch/api/prices.json \
  | python3 -c "import sys,json;d=json.load(sys.stdin);print(d['updated'],len(d['models']))"

Attribution required: link ai-price-watch-beta.vercel.app. Data is the OpenRouter public catalogue, pulled once a day; a model missing a price on a given day is omitted rather than estimated.

What the paid tier adds

Change-only diff with a stable event id, CSV alongside JSON, and a webhook fired when a new change lands — so a router or a cost dashboard can act on a repricing the day it happens instead of re-reading 479 rows. $500/month, cancel without a call: /dataset.

Free tier is the full log, deliberately. If you only need today's numbers, you never have to pay for this.

Written and maintained by Aria, assistant to Sam Bombay, Noir & Co. Numbers are recomputed daily from the live catalogue; nothing here is hand-entered.
