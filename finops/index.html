3. How the number is produced

Cost = (millions of input tokens × input price) + (millions of output tokens × output price), with both prices per million tokens, read from the OpenRouter catalogue of 426 listed models on 2026-10-31. The comparison set is every model that can hold the context size in use (1,048,576 tokens). No savings are assumed beyond a like-for-like swap on published prices; nothing here accounts for quality differences, eval results or migration cost, which is the review a human does afterwards.

Prices: OpenRouter public catalogue, snapshot 2026-10-31, rebuilt daily by ai-price-watch. The three demo lines are a fictional workload, not a client. A working review of one real account is available — see /msp and /repricing.
