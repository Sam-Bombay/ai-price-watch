What happened, in one paragraph

On 27 November 2026 Malspark published a scan of all 3.27 million public Hugging Face model repositories. It found five malicious GGUF files, downloaded 2,428 times at the time of writing, across two campaigns. Mir2k appended a Windows remote-access trojan after the last tensor of two models, then two to four days later rewrote their chat templates so the model opens every reply with a PowerShell line that carves the payload out of its own file and runs it. timdedid used the template alone: a trigger phrase inserts a fake [SYSTEM DIRECTIVE] telling an agent with shell access to fetch and run a script. No exploit, no escalation — ordinary template logic. Source: malspark.com, 27 Nov 2026.

What this watch actually reads

For every public GGUF repository created in the last seven days it reads the declared chat_template from the model metadata and runs fifteen patterns taken from the YARA rules published with the report — PowerShell invocation, [IO.File]::OpenRead, WriteAllBytes, DeflateStream, Start-Process, .Length-, [SYSTEM DIRECTIVE], -WindowStyle Hidden, covert-instruction text, Jinja dunder escapes, and base64 blobs. Nothing is downloaded and nothing is executed.

Validated before use. Run against synthetic templates built from the published indicators, the rule set fires six patterns on the Mir2k armed-template shape, five on the timdedid shape, two on a covert-instruction template, and zero on an ordinary chat template. A detector that never fires is not a detector.

  • Window: 7 days. Repositories scanned: 350. Templates readable: 241 — 109 of 350 published no chat template at all, which is itself a finding: a file you cannot read the template of is a file you cannot clear.
  • Today's result: 0 templates matched a published attack pattern. A clean day is a baseline, not a safety certificate.
  • The scanner is gguf_watch.py, free and read-only, refreshed daily with the price pull.

What this watch does not read — stated, not buried

Templates only. It does not inspect bytes appended after the last tensor, so it would not have caught Mir2k's payload by itself before the template was armed — only the arming. It does not run antivirus, it does not hash weights, and file sizes cannot prove absence of an overlay. If you need the file bytes cleared, that is a per-file job with a rebuild, and it is what the paid check below does.
